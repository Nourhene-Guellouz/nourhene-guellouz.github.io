Automated Testing Framework

Capstone Project - Samsung Innovation Campus

Project Overview

This project involves building an automated testing framework to streamline software testing processes. The framework integrates advanced data analysis and visualization tools to improve the accuracy and efficiency of tests.

Key Features

  • Developed dynamic locators for automated testing.
  • Integrated data visualization tools like Grafana for test analysis.
  • Implemented Continuous Integration using Jenkins.
  • Optimized performance monitoring using Prometheus and VNC integration.

My Contribution

During this capstone project, I worked extensively on:

  • Developing dynamic locators using data science techniques to enhance test accuracy.
  • Automating the testing pipeline with Jenkins for seamless integration.
  • Creating insightful visualizations with Grafana to monitor test results.
  • Integrating containerization tools like Docker for scalable execution.

Training Context

This project was part of the Samsung Innovation Campus training, which provided hands-on experience in:

  • Automation and optimization of software testing processes.
  • Using cloud-based platforms and tools like Docker and Jenkins.
  • Working with modern testing frameworks and monitoring tools.
