Automated Testing Framework

PFE Project at DigitalBerry

Project Overview

This project was carried out as part of my PFE (Projet de Fin d'Études) internship at DigitalBerry. It involved the automation and optimization of processes for their application, BerryCert, using modern tools and techniques.

Key Responsibilities

  • Developed a data analysis framework using Python to automate test results for the BerryCert application.
  • Implemented real-time data visualization and performance monitoring with Grafana, enabling decision-making based on critical indicators.
  • Designed and optimized advanced algorithms to extract and analyze data from HTML structures, improving analysis accuracy by 40%.
  • Automated data collection and processing workflows using Jenkins and Docker, reducing manual interventions by 30% and increasing pipeline efficiency.
  • Used Prometheus for performance monitoring, log analysis, and prediction, ensuring optimal resource management and critical data analysis.
  • Structured and managed data with PostgreSQL, enhancing its accessibility and traceability for advanced analysis.

Technologies Used

  • Python
  • PostgreSQL
  • Jenkins
  • Grafana
  • Prometheus
  • Docker
  • Selenium
  • JavaScript
