Secure CI/CD & Automated Testing Framework

PFE Internship Project at DigitalBerry

Project Overview

This DevSecOps project aimed to build a secure and automated testing pipeline for the BerryCert application. It was completed during my end-of-studies internship at DigitalBerry, focusing on optimizing test execution, monitoring, and integration through modern tools.

Key Responsibilities

  • Engineered a Python-based framework for test automation and performance analysis of BerryCert.
  • Built dynamic XPath locators to improve test accuracy by 40%.
  • Set up continuous integration workflows using Jenkins and Docker to cut manual workload by 30%.
  • Integrated Prometheus and Grafana for real-time monitoring and log visualization.
  • Managed PostgreSQL-based logging systems for efficient test data tracking and analysis.
  • Collaborated with DevOps and QA teams to streamline deployment and testing processes.

Technologies Used

  • Python, PostgreSQL
  • Jenkins, Docker, Prometheus, Grafana
  • Selenium, JavaScript
  • XPath, Bash scripting
